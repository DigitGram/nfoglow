# Security Policy

## Supported versions

Only the latest release gets security fixes.

## Reporting a vulnerability

Please do **not** open a public issue for a security problem. Use GitHub's private reporting instead:
**Security** tab of this repository, then **Report a vulnerability**.

Please include what you found, how to reproduce it and which version it affects. You will get an answer as soon as possible; this is a one-person project, so please allow a few days.

## Verifying what you download

The files of every release (`install.sh`, the `.deb` and the Flatpak bundle) are covered by a GPG-signed `SHA256SUMS` (`SHA256SUMS.asc`). How to check it is in the README under "Verify the download".
